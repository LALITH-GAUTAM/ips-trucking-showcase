# IPS Trucking Website

[View published preview](https://ips-driven-web.lovable.app/) · [Developer profile](https://github.com/LALITH-GAUTAM)

A responsive transportation website that presents IPS Trucking's services and guides customers through a freight inquiry.

## My work

- Website branding and photography presentation.
- Responsive transportation service layouts.
- Five-step shipment inquiry interface: contact details, route, shipment requirements, optional attachments, and consent.
- GitHub delivery and hosting previews.

## Technology

React, TypeScript, TanStack Start, Tailwind CSS, React Hook Form, and Zod.

## Current status

Published preview. The inquiry interface includes validation, attachment checks, and submission states. Quote and contact delivery endpoints are not configured; inquiry delivery is pending.

## Project record

This repository is the public showcase. Application source is maintained privately in `ips-trucking-website`. The preview hostname retains the original `ips-driven-web` identifier.
